What ArchHub is

A drafting table for AI.

A desktop workspace where every action is a node on one canvas — hosts, AI turns, filters, connector ops, wired together. The Composer proposes edits to that graph; you approve each line before it is drawn. The graph is parametric and replayable: nudge a value, and the chain downstream re-cooks. It runs with or without an agent — drive it by hand, or let the Composer drive.

01 · THE SURFACE
◈

Canvas

Every action is a node; every node is replayable. Drag a parameter and the chain downstream re-runs. Nothing happens that you can't see, trace, or undo. Always directly editable — right-click, drag-rewire, edit params inline.

02 · THE HAND
✎

Composer

Talk to the project. The Composer proposes edits to the graph; you approve the line before it's drawn. Every write to a host is approval-gated by default and reversible. The canvas is the materialised, inspectable result.

03 · THE MEMORY
❖

Brain

Persistent cross-session memory and reusable Skills that grow with your firm. Save any thread as a Skill — plain JSON you own, versioned in your own GitHub repo. No marketplace, no lock-in.

HOW IT WORKS
How it works

From host to output.

1

Wire a host

Drop a Revit, Rhino, AutoCAD, or Excel node on the canvas. ArchHub probes the host and shows its honest live status.

2

Ask the Composer

Describe the work in plain language. The Composer drafts a chain of nodes and shows you the line before it draws it.

3

Approve the line

Review the proposed graph. In Plan mode, every write waits for your nod. Tune a parameter and the chain re-cooks downstream.

4

Replay & reuse

Output to a sheet set, a file, or another host. Save the chain as a Skill in your own repo, and run it on the next project.
