# Security

Do not post credentials, user graphs, client data, or exploit details in public issues.
Use [GitHub's private vulnerability reporting entry point](https://github.com/Fargaly/ArchHub/security/advisories/new) if available. Availability depends on repository settings; this file does not enable the feature.
If private reporting is unavailable, open a public issue requesting a private reporting channel without including sensitive details.
Include the affected version, reproduction steps using synthetic data, impact, and a suggested fix when reporting privately. Keep credentials in their existing OS-protected store.
